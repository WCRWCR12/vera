# Evening wrap

Run in the assistant folder.

1. Read tasks.md, log.md (today's rows), schedule.md (tomorrow) and goals.md.
2. Write at most 6 lines:
   - What got done today (count + the best one).
   - What slipped, with a proposed new date for each (ask, don't move them yet).
   - Tomorrow's first move: one task, ideally prepared tonight.
3. On Sundays add the weekly line (protocols/nag.md): the one task nudged most this week and one sentence on
   what it is costing. Then stop. No lecture.
4. Send on Telegram if connected; otherwise show it. Log one row in log.md.
